# 简易通量 FluxLite

[![Build](https://github.com/lanStar2003/FluxLite/actions/workflows/build.yml/badge.svg)](https://github.com/lanStar2003/FluxLite/actions/workflows/build.yml)
[![Release](https://img.shields.io/github/v/release/lanStar2003/FluxLite)](https://github.com/lanStar2003/FluxLite/releases/latest)

GTNH 2.8.4（Minecraft 1.7.10，GT5-Unofficial 5.09.51.482）的简化版通量网络。
不建网络、不设密码、不用配置：**GT 无线电网就是网络**，团队成员自动共享。

## 方块

| 方块 | 作用 |
| --- | --- |
| 通量连接器 | 一个小核心，四周有机器、仓室或线缆就自动伸出连接臂接上，并自动判断方向；有连接时自带区块加载 |
| 通量控制中心 | 查看团队所有设备当前的输入输出、实时曲线、排行、单设备详情和告警；有人靠近时在上方浮现全息显示屏；可选告警红石输出 |

### 方向（以无线电网为视角）

| 相邻 | 方向 | 连接臂颜色 |
| --- | --- | --- |
| 发电机、动力仓 | **输入**：电进入网络 | 绿 |
| 能源仓、耗电机器 | **输出**：网络供电给设备 | 橙 |
| 同时挂着发电和用电设备的 GT 线缆 | **双向** | 蓝 |
| 能读出连接但没有设备 / 读不出规格 | 待机 / 无法识别 | 灰 / 红 |
| 被玩家关掉的面 | 已停用 | 深灰 |

- 连接器界面只有两样东西可改：**名称**，以及**每一面的开关**。
- **电压安全**：供电电压严格等于目标的额定输入；接线缆时取「最弱线缆」与「线缆上最低的机器输入电压」的较小值。读不出规格的设备不会被供电。
- 双向线缆不会自己给自己绕圈：连接器往线缆送电的那一刻，所有连接器都拒收电，所以发电机的电和网络的电不会在线缆里来回打转。

### 扳手

支持 GT 扳手，以及 BuildCraft、CoFH、AE2、EnderIO、Mekanism、IC2 的扳手（和带 Forge 工具类型 `wrench` 的物品）：

| 操作 | 连接器 | 控制中心 |
| --- | --- | --- |
| 右键 | 点哪一面就开关哪一面 | 转向被点的那一面（点正面、顶面、底面则旋转 90°） |
| 潜行右键 | 拆进背包，保留名称和关掉的面 | 拆进背包，保留红石 / 全息投影开关 |

只有所属团队或 OP 可以用扳手操作；会消耗扳手耐久。用镐挖掉则不保留设置。

### 供电平稳

GT 本身按「整包」送电：机器缓存有空位才收一整包（电压 × 1A），所以按 tick 看总是一下有、一下没有。连接器的做法与 GT 无线能源仓一样，**每 tick 把机器缓存补满**：

- **直连的 GT 机器 / 仓室**：整安培按额定电压送，剩下不足一包的部分用一个小电压包补上（GT 接受任何不高于额定电压的包），缓存每 tick 正好满，供电量等于机器实际用量。
- **直连的发电机 / 动力仓**：除了 GT 自己推过来的整包，每 tick 再把高于最低存量的余电抽走，所以发电读数也是平稳的；两者合计不超过额定输出。
- **线缆**：保持 GT 原样（线缆的电流上限、损耗、烧线规则都不变），读数用下面的算法消除跳动。

### 「当前」读数怎么算

界面、Waila、全息屏上的「当前 EU/t」按**包与包之间的间隔**计算：取最近至少 20 tick 内的若干个包，用它们的总能量除以首尾间隔。
所以每 16 tick 收一包 32 EU 的机器稳定显示 2 EU/t，不会在 0 和 32 之间跳；开始用电立即显示；停电后几个包的时间内归零。

### 支持的线缆与设备

| 类型 | 方式 |
| --- | --- |
| GT 线缆与机器 | 直接调用 GT 的能量接口；线缆会扫描整条网络（节点上限可配） |
| IC2 导线与机器 | 连接器注册进 IC2 能量网；导线会扫描找出两端设备，输出等级取线上最低耐压 |
| RF 设备与导管（如 EnderIO） | CoFH 接口，换算比例读 GT 配置（`mEUtoRF` / `mRFtoEU`）。导管同时能收能发时按「输入」处理 |

### 结算

每个面有很小的收集缓冲和供电缓冲。默认**每 tick** 按团队结算一次：先把收集到的电存入无线电网，再补满各面的供电缓冲；余额不够时按需求比例分配。
方块被拆或区块卸载时，缓冲余额立即退回无线电网（在区块存盘前完成，不会重复计算）。

### 区块加载

有连接的连接器加载周围区块（默认半径 1，即 3×3），按区块引用计数、票据池化复用，重启后从注册表恢复。
Forge 默认每个模组 200 张票、每票 25 个区块，不够时会告警，可在 `config/forgeChunkLoading.cfg` 里给 `fluxlite` 调高。

## 控制中心

| 页面 | 内容 |
| --- | --- |
| 总览 | 输入 / 输出 / 净值（当前 EU/t）、无线电网余额与耗尽预估、能量流曲线（实时 10 秒，或 1 小时 / 24 小时平均）、用电最多与发电最多 |
| 设备 | 每个面（精确计量）和线缆后面的每台 GT 机器（`~` 开头，读 GT 自身统计）。筛选：方向（全部 / 输入 / 输出 / 双向）、状态（运行中 / 空闲 / 离线 / 已关闭 / 无法识别，带数量）、电压等级、所属连接器、类型（直连设备 / 线缆 / 线缆后的机器），加搜索和一键清除；点表头排序、滚轮翻动；底部显示筛选结果的数量与合计输入输出；点一行看详情 |
| 详情 | 当前值、1 小时峰值和发生时间、供电满足率、运行时间占比、累计和今日、实时 / 1 小时 / 3 天曲线、24 小时分布、线缆后机器的缓存占比、定位高亮 |
| 告警 | 余额过低、耗尽预估过短、供电不足、负载过高、长时间无流动、区块加载失败、无线电网不可用；聊天提示、红石输出、全息投影三个开关 |

### 全息显示屏

玩家走到控制中心附近（默认 12 格，可配置）时，顶部的投影镜头射出一道光，一块全息面板在方块上方展开：先是一条亮线横向拉开，再纵向展开成玻璃面板，内容闪烁着浮现；走远后折叠收起。面板朝向和控制中心的屏幕一致，轻微上下浮动，从背面只看到玻璃。

面板内容参考 GTNH 的工业信息面板：团队状态（正常 / 告警数 / 电网不可用）、网络余额、净流量与耗尽预估、输入 / 输出、最近 10 秒曲线、连接器在线数。
数据每 0.5 秒只发给范围内的玩家；所属团队可在控制中心「告警」页关掉投影，服务器可把 `hologramRange` 设为 0 全部关闭。

OP 可以在控制中心切换查看所有团队。统计的分钟级、小时级和累计值存在 `data/fluxlite_registry.dat`，重启后保留。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/fluxlite balance [玩家]` | 查看团队无线电网余额 |
| `/fluxlite add <EU> [玩家]` | （OP）增减余额，可为负数 |
| `/fluxlite team [玩家]` | 查看团队队长 |
| `/fluxlite status` | 已加载连接器数、注册表记录数、各维度强制加载区块数 |
| `/fluxlite settle` | （OP）立即结算一次 |

## 配方

GT 装配机配方（可在配置里改电压等级或关闭，改用 CraftTweaker 脚本）：

- 通量连接器（默认 UV）：机器外壳、ULV 无线能源仓、传感器 ×2、发射器 ×2、电路板 ×2、中子素板 ×4，焊锡 576 L
- 通量控制中心（默认 LuV）：机器外壳、屏幕覆盖板、能量探测覆盖板、传感器、电路板 ×2，焊锡 576 L

## 配置

`config/fluxlite.cfg`：结算周期（默认 1 tick）、无线损耗（默认 0）、每团队连接器上限、区块加载开关 / 半径 / 离线策略、线缆扫描节点上限与重扫间隔、告警阈值、配方等级、RF 名义电压、全息显示屏范围（`display.hologramRange`，0 = 关闭）。

## 下载

在 [Releases](https://github.com/lanStar2003/FluxLite/releases) 页面下载 `fluxlite-<版本>.jar`，放进 GTNH 实例的 `mods` 文件夹。`-dev` 和 `-sources` 两个 jar 是给开发用的。

## 构建

需要 JDK 25（`.java-version`）：

```bash
./gradlew build
```

产物在 `build/libs/fluxlite-<版本>.jar`；版本号取自 git 标签；也可以用 `VERSION=0.4.0 ./gradlew build` 指定。

推送到 `main` 时，GitHub Actions 会自动构建并跑测试，jar 和界面预览图作为构建产物上传。
推送版本标签（如 `0.4.0`）会自动构建并发布 Release，发布说明取自 [CHANGELOG.md](CHANGELOG.md) 的对应小节：

```bash
git tag 0.4.0 && git push origin 0.4.0
```

界面、方块模型和全息显示屏可以不进游戏预览：`./gradlew test` 会用原版字体把它们渲染到 `build/previews/*.png`（`holo_scene.png` 是控制中心加全息屏的等轴视图）。
